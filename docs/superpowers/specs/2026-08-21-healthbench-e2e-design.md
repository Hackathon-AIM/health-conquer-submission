# HealthBench E2E 검사기 설계

## 목표

HealthBench 원문을 사용하지 않고, 합성한 영어·한국어 대화로 제출 서비스와 MCP 연결을 함께 점검한다.

## 범위

- 실행 중인 OpenAI 호환 서비스의 `/health`, `/v1/models`, `/v1/chat/completions`를 확인한다.
- 영어·한국어 멀티턴, 영어·한국어 응급 응답을 검사한다.
- 실제 MCP의 문서 인덱스 검색과 페이지 열람을 별도로 왕복해 `cite_uid`와 본문을 확인한다.
- 질문·응답 원문과 MCP 문서를 파일로 저장하지 않는다.

## 경계

- `scripts/healthbench_e2e.py`는 표준 라이브러리만 사용한다.
- `--skip-mcp`로 서비스 검사만 실행할 수 있다.
- 실제 네트워크 호출은 스크립트를 실행할 때만 발생한다. 자동 테스트는 로컬 가짜 HTTP/MCP 서버를 사용한다.
- HealthBench 데이터·rubric·holdout 문항을 읽거나 포함하지 않는다.

## 성공 기준

1. 네 가지 합성 대화가 OpenAI 호환 형식으로 전송되고 비어 있지 않은 답을 받는다.
2. 영어·한국어 답변 언어와 응급 첫머리 행동 문구를 판정한다.
3. MCP가 도구 목록, 관련 노드, 페이지 본문을 반환하며 본문 항목에 `cite_uid`가 있다.
4. 어느 검사든 실패하면 종료 코드 1과 실패 검사명을 출력한다.
